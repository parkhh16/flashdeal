# 2라운드 디자인 방향: "수량이 정해진 물건을 고르는 갤러리"

범위는 `frontend/`의 고객 화면이다(공통 헤더, 쇼핑 목록 `/`, 상품 상세 `/products/:id`, 내 활동 `/me`, 로그인/회원가입).
관리자 `/admin/*`는 3라운드다. 이번에는 공유 토큰 값이 바뀌어도 깨지지 않는지만 본다(8장).
1라운드 문서(`tokens.md`, `pages.md`)는 수정하지 않는다. 토큰 이름은 유지하고, 바뀐 값과 새 토큰은 이 문서 5장에 적는다.
페이지별 개선안과 수용 기준은 [round2-pages.md](round2-pages.md).

## 방향 (한눈에)

1. **분위기**: 이미지가 주인공인 갤러리. 따뜻한 종이색 바탕(라이트) / 따뜻한 먹색 바탕(다크)에 사진이 크게 놓이고, UI는 뒤로 물러난다. "재고가 정해진 상품만 고른 가게"라는 정체성은 문구와 정보 위계로 드러내고, 시간 압박은 쓰지 않는다.
2. **타이포**: 시스템 폰트 스택 그대로. 위계를 크기와 굵기 차이로 만든다. 히어로 제목 28~44px / 800 / 자간 -0.03em, 가격은 18~32px / 800, 보조 글자는 12~13px / 500. 지금처럼 14px/600 한 가지로 전부 말하지 않는다.
3. **색**: 잉크(거의 검정)와 종이가 면의 90%. 주황(`--accent`)은 "행동(구매, 검색)"과 "한정/할인 신호(할인율, 남은 수량 칩)" 두 가지에만 쓴다. 히어로 한 곳만 어두운 면을 써서 첫 화면에 무게 중심을 만든다(다크 모드에서는 따뜻한 갈색 면).
4. **모서리/그림자**: 모서리를 키운다(카드 이미지 16px, 패널 20px, 입력/버튼은 알약 또는 12px). 평소 그림자는 없고, hover/고정 바/메뉴에서만 부드러운 그림자.
5. **모션**: 짧고 한 방향. 카드 hover 때 이미지 1.04배 확대(0.25s), 누르면 0.98배, 스켈레톤 shimmer, 처리 중 회전 링. 깜빡임, 흔들림, 카운트다운 애니메이션, 반복 모션 없음. `prefers-reduced-motion`이면 전부 정지.

## 2. 모티브: 어떤 원칙을 어디서 가져왔나

특정 사이트의 화면 구성, 문구, 로고, 에셋은 옮기지 않는다. 아래는 원칙만이다.

| 원칙 | 가져온 곳(유형) | 이 문서에서 쓰는 곳 |
|---|---|---|
| 이미지 우선 그리드: 사진을 크게, 글은 사진 밖에 짧게 | 패션 큐레이션 커머스 | 카드 구조(3장), 첫 행 대표 카드 2x2 |
| 가로 카테고리 레일: 카테고리를 사이드 트리 대신 한 줄 칩으로 | 국내 종합 커머스의 상단 카테고리 줄 | 목록의 카테고리 레일(pages 2장) |
| 상단 고정 검색: 어디서든 검색이 닿는다 | 대형 마켓플레이스 | 헤더 검색(pages 1장) |
| 모바일 하단 고정 구매 바: 가격과 구매 버튼이 항상 엄지 닿는 곳 | 모바일 커머스 앱 전반 | 상세 구매 바(pages 3장) |
| 가격 위계: 할인율 → 현재가 크게 → 원가 작게 취소선 | 국내 커머스 카드 | 카드/상세 가격 블록 |
| 한 곳의 어두운 히어로: 첫 화면에 무게 중심과 브랜드 톤 | 전자제품 브랜드 스토어의 에디토리얼 배너 | 목록 히어로(pages 2장) |
| 카드 hover/press 피드백, 스켈레톤이 실제 카드와 같은 치수 | 앱형 쇼핑몰 | 3장 모션, 스켈레톤 |
| 접이식 안내(상세 하단 정책 영역 `details`) | 모바일 커머스 상세 | 상세 안내 섹션 |
| 정직한 희소성: 남은 수량은 사실로만 쓰고 시간 압박은 쓰지 않는다 | 이 프로젝트 원칙(설계 규칙 8, 1라운드 공통 제약) | 재고 칩, 품절 오버레이 |

## 3. 카드 구조 (before → after)

| | before | after |
|---|---|---|
| 이미지 | 1:1, 모서리 10px, 위에 `품절` 배지 | 1:1, 모서리 16px, 이미지 위에 **상태 칩**(남은 수량), 품절은 이미지 전체를 덮는 스크림 + 가운데 "품절" |
| 카테고리 | 12px `키보드 · 무선` 줄 | 12px muted, 이미지 바로 아래(유지) |
| 상품명 | 14px / 600, 2줄 | 15px / 600, 2줄 고정 높이 |
| 가격 | 한 줄에 `13% 139,000원`, 원가는 다음 줄 | 한 줄에 `13%`(accent-text 15px/800) + `139,000원`(18px/800) + 원가(12px 취소선 muted). 원가는 같은 줄 끝, 좁으면 줄바꿈 |
| 구매 제한 | 12px 문장 "1인 2개 구매 가능" | 12px muted "1인 2개까지"(유지, 짧게) |
| 남은 수량 | 가격 아래 칩 | **이미지 왼쪽 아래 칩**(`--warn-weak`/`--warn`, 12px/700, pill) |
| hover/press | 제목 밑줄 | 이미지 확대 1.04, 카드 전체 `:active` 0.98, 포커스 링 |
| 대표 카드 | 없음 | 홈 무필터 + 너비 1024px 이상일 때 첫 카드는 2x2 크기(이미지 크게, 이름 20px) |

이미지가 없을 때 placeholder는 1라운드 규칙(카테고리 이름 글자)을 유지하되 이모지 대신 인라인 SVG 아이콘(40px, 1.75px 선)을 쓴다.

## 4. 아이콘/이미지 규칙

- 아이콘은 모두 인라인 SVG, 24x24 viewBox, `stroke="currentColor"`, 선 굵기 1.75, `fill="none"`, 둥근 끝. `aria-hidden="true"`. 새 라이브러리 없음. 필요한 것: 로고 마크, 검색, 닫기, 5개 카테고리(키보드, 마우스, 모니터, 헤드폰, 액세서리), 빈 상태 돋보기, 처리 중은 CSS 링(기존).
- 로고: 28px 라운드 사각형(`--accent` 면) 안에 흰(다크는 `--on-accent`) 번개 모양 SVG + 워드마크 "니즈샵"(800, 자간 -0.02em). 이모지 `⚡` 제거.
- 외부 폰트, 외부 이미지, CDN 없음. 히어로 배경은 CSS `radial-gradient`만 쓴다(이미지 파일 없음).

## 6. 모션 규칙

- 카드 hover: `@media (hover: hover)`에서만 이미지 `transform: scale(1.04)`, 이미지 컨테이너는 `overflow: hidden`, 전환 `var(--dur-2) var(--ease)`.
- 카드 press: `:active` `transform: scale(.98)`, `var(--dur-1)`.
- 스켈레톤 shimmer는 기존 유지. 카드 스켈레톤은 새 카드와 같은 치수(이미지 정사각형, 제목 2줄, 가격 1줄)여서 로딩 끝에 레이아웃이 튀지 않는다.
- 하단 구매 바, 히어로, 헤더는 등장 애니메이션 없음(처음부터 그 자리).
- `@media (prefers-reduced-motion: reduce)`: 모든 transform 전환, shimmer, 회전 링 정지.
- 금지: 점멸, 펄스, 카운트다운 숫자 애니메이션, 반복 흔들림.

## 7. 구현 순서 (한 번에 한 종류씩)

각 단계가 끝날 때마다 `npm run build`와 스크린샷 비교를 거친다. 앞 단계가 뒷 단계를 막지 않게 쪼갰다.

1. **토큰**: `index.css` `:root`/다크 블록에 5장 값 반영, 로고/카테고리 SVG 컴포넌트(`components/icons.tsx` 새 파일, 외부 의존 없음). 화면은 색과 모서리만 바뀐다. 관리자 화면 회귀를 이때 확인한다(8장).
2. **헤더**: 로고 마크, 검색을 헤더로 이동, 모바일 2줄 헤더, 계정 아바타. 사이드바 제거(고객 화면), 햄버거 제거. 이 단계에서 카테고리 접근이 없어지므로 3단계와 같은 PR로 묶거나, 사이드바 제거는 3단계에서 한다(권장: 헤더 단계에서는 사이드바를 남기고 3단계에서 제거).
3. **목록**: 히어로, 카테고리 레일, 카드, 대표 카드, 빈/로딩/에러 상태, 사이드바 제거.
4. **상세**: 갤러리, 구매 패널, 하단 구매 바, 구매 제한 한 곳으로 통합, 접이식 안내.
5. **내 활동**: 주문 카드, 2열 레이아웃, 상태 표시.
6. **로그인/회원가입**: 로고 포함 카드, 배경 글로우. (3~5단계와 독립이라 마지막.)

## 8. 관리자 화면 영향 (건드리지 않고 확인만)

`admin.css`는 `--bg`, `--surface`, `--surface-2`, `--border`, `--text`, `--muted`, `--accent`를 쓴다. 위 표대로 값만 바뀌며 대비는 모두 기존 이상이다(muted 5.73→6.94 등). `--radius`가 10→12px로 커지는 것은 허용한다. 확인 항목: 관리자 표/탭이 가로로 넘치지 않는지, 비활성 버튼과 처리 중 버튼이 1라운드와 같은지. 이 라운드에서 `admin.css`를 고치는 것은 토큰이 깨졌을 때의 최소 수정만 허용한다.

## 9. 공통 제약 (1라운드에서 그대로 이어짐)

- 결제/주문/제출 버튼: 처리 중 `disabled` + `aria-busy="true"` + 회전 링 + 글자("주문 중…", "결제 중…"). 하단 고정 구매 바의 버튼도 같은 규칙이다(pages 3장).
- PAYING, UNKNOWN은 `--unc` 점선 + "결제 확인 중"으로 확정 전임을 보이고, 취소/재결제 버튼을 두지 않는다.
- AI 검색, 카테고리 트리, 활동 로그가 실패해도 목록과 주문 화면 레이아웃은 정상이다. 히어로와 "남은 수량이 적은 상품" 레일은 상품 목록 응답만으로 그린다.
- 카운트다운(상품 목록/상세), 판매율 막대, 깜빡임, "마감 임박" 문구 없음. (내 주문의 "결제 기한 m:ss"는 기존 기능이며 새 강조를 얹지 않는다.)
- 새 라이브러리 없음. 외부 웹폰트 없음. API 필드와 서버 변경 없음.
